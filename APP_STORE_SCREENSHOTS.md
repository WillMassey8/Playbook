# App Store screenshots — sizes & shot list

## Required sizes (iPhone)

| Device class | Portrait size | Priority |
|--------------|---------------|----------|
| 6.7" (iPhone 15 Pro Max) | 1290 × 2796 | Required |
| 6.5" (iPhone 11 Pro Max) | 1284 × 2778 | Required if supporting |
| 5.5" (iPhone 8 Plus) | 1242 × 2208 | If supporting older |

Capture on a real device or Simulator → File → New Screen Recording / Screenshot.

## Shot list (5–6 frames)

1. **Home / feed** — muted clip autoplaying in-app  
2. **Share sheet moment** — “Saved to Playbook ✓” (extension)  
3. **Full-screen intake** — “Where does this go?” categorize  
4. **Playbook categories** — Pass / Run / RPO browser  
5. **Clip detail** — source attribution visible  
6. **Profile** — Sign in with Apple / Delete Account visible (optional)

## Tips

- Use light or dark consistently; avoid debug `?skip=1` chrome in final shots  
- No competitor marks in screenshots  
- Prefer real shared X/TikTok public clips, not lorem
